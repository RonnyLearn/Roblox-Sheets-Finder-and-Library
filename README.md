# Roblox Sheets — Finder and Library

Программа для Windows: поиск нот для Roblox-пианино на разных сайтах, личная библиотека песен, транспозиция, упрощение аккордов, перевод MIDI в ноты

## Скачать

Откройте раздел [Releases](../../releases/latest) и скачайте архив `Roblox-Sheets-<версия>.zip`.

1. Распакуйте архив в любую папку.
2. Запустите `Ноты.exe`.
