# Roblox Sheets — Finder and Library

Программа для Windows: поиск нот для Roblox-пианино на разных сайтах, личная библиотека песен, транспозиция, упрощение аккордов, перевод MIDI в ноты и отправка нот в PianoGlow.

## Скачать

Откройте раздел [Releases](../../releases/latest) и скачайте архив `Roblox-Sheets-1.0.zip`.

1. Распакуйте архив в любую папку.
2. Запустите `Ноты.exe`.
3. Введите код доступа и нажмите «Активировать».

Для работы нужен код доступа (подписка). Один код работает на одном компьютере.
